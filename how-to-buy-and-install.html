วิธีสั่งซื้อและติดตั้ง DogFlow Auto Gen ใน 4 ขั้นตอน

ตั้งแต่สมัครสมาชิกจนถึงเริ่มใช้งานโปรแกรม ทุกอย่างทำผ่านเว็บร้านนี้ ไม่ต้องรอส่งไฟล์ทางแชต

  1. สมัครสมาชิก — สมัครฟรีด้วยอีเมล เพื่อรับคีย์และไฟล์ติดตั้งในบัญชีของคุณ
  2. เลือกแพ็กเกจและโอนเงิน — ร้านมีแพ็กเกจรายเดือน รายปี และตลอดชีพ ดูราคาล่าสุดได้ที่หน้าแพ็กเกจ สแกน QR โอนเงิน แล้วแนบสลิป ระบบตรวจยอดให้อัตโนมัติ
  3. รับ License key — แอดมินยืนยันแล้ว คีย์จะส่งเข้าหน้าโปรไฟล์ทันที
  4. ดาวน์โหลดและใส่คีย์ — โหลดโปรแกรมเวอร์ชันล่าสุดในหน้าโปรไฟล์ ติดตั้งแล้วใส่คีย์ ไฟล์ติดตั้งสำหรับสมาชิกที่มี License เท่านั้น

อัปเดตโปรแกรมเมื่อมีรุ่นใหม่

เมื่อมีเวอร์ชันใหม่ โปรแกรมจะแจ้งเตือนและมีปุ่ม "อัปเดตเลย" ให้ระบบดาวน์โหลดและติดตั้งให้เอง ไม่ต้องโหลดไฟล์มาทับเอง หากอยากอัปเดตเอง ก็โหลดไฟล์ติดตั้งจากหน้าโปรไฟล์ได้

License ใช้ได้กี่เครื่อง

แต่ละ License ใช้ได้ตามจำนวนเครื่องที่ระบุในแพ็กเกจ และดูรายชื่อเครื่องที่ใช้งานอยู่ได้ในโปรแกรม ห้ามแชร์คีย์ต่อ ดูเงื่อนไขและกฎการใช้งานที่ท้ายหน้าร้าน

ก่อนซื้อ ตรวจสอบเครื่อง

  • ต้องมี Gemini Ultra หรือ Pro
  • ใช้บน Windows (Notebook / PC)
  • ใช้ผ่านเบราว์เซอร์ Google Chrome หรือ Microsoft Edge
  • ไม่รองรับมือถือ / iPad / Tablet

ยังไม่แน่ใจว่าเหมาะกับงานของคุณไหม ดูฟีเจอร์ทั้งหมด หรือตัวอย่างคลิปที่สร้างด้วยโปรแกรมก่อน หรือทักไลน์สอบถามจากหน้าแรก
